## How to structure my Python package code ?

1. Under a feature or learning topic, we can spilt it into 3 parts : 
    - Exploration and Learning (use notebook like .ipynb)
    - Practice with Clean code (use .py)
    - Summary of a topic (use .md)

2. You can choose this rule:
    - .md → notes
    - .py → code
    - .ipynb → only when data / visualization / step-by-step learning helps
    
That’s a very mature approach.
